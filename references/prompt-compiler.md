# Prompt Compiler

Write four compact paragraphs in this order.

## 1. Canvas and attention

State the ratio, paper tone and defects, open-paper share, cluster scale and direction, and explicit rejection of regular cards or template grids.

## 2. Image contracts and structural thesis

For each input, name its role and preservation level. For a style reference, list only reusable traits and forbid its subject, text, interface, exact layout, and accent shape. For an edit target, state invariants, permitted changes, and analytical elements. Name one thesis and one deconstruction grammar. Explain how every photo fragment and drawing relation contributes to that thesis.

## 3. Typography and palette

State the exact short title and up to three labels, language constraint, photo reduction palette, exact source-derived accent hue and rationale, visible carrier, approximate accent area, and print defects.

## 4. Reproduction and avoids

State the flat orthographic scan, contrast, mood, and the shortest relevant avoid list.

## Template

```text
Landscape 4:3 deconstructivist travel-zine site-analysis poster on full-frame [paper] with [texture]; no border and no mockup. Keep [open_share]% as open paper. Build one asymmetric analytical event occupying [cluster_share]% at [position/direction]. Avoid regular grids, equal cards, and template composition.

Use Image 1 as [role] with [preservation]. Keep [invariants] recognizable. Allow changes only to [permitted changes]. Translate the subject into “[structural thesis]” using [deconstruction grammar]. Create [concrete photo fragments] and connect them with [concrete drawing relations]. Every element must explain the same system rather than act as decoration.

Use only [language constraint]. Set the exact title “[title]” with labels “[label 1]”, “[label 2]”, and “[label 3]”. Reproduce photo fragments in [reduction palette]. Use [accent name and hex] as the sole saturated accent because it derives from [source relationship], carried by [structural carrier] and occupying about [accent share]% of the canvas. Apply [print defects].

Flat orthographic scanned-paper appearance, diffuse light, low-to-medium contrast, [mood]. Avoid [relevant avoids].
```

## Compilation checks

- Name visible objects, fragments, and lines rather than abstract design adjectives alone.
- `Deconstructivist` does not substitute for explaining what is cut, displaced, folded, rotated, or linked.
- `Industrial drawing` does not authorize random dimensions or fake technical data.
- Low saturation applies to photographs and supporting ink, not necessarily to the small accent.
- Do not request a large source-color field and a small accent simultaneously; suppress the large field first.
