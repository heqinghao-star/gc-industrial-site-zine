# Reference Analysis

Inspect every usable reference and record dimensions, ratio, paper field, negative space, fragment count, fragment geometry, analytical connections, typography, color roles, reproduction defects, and sample-specific residue.

Separate:

- **Observed:** directly visible traits such as torn halftone fragments, a dashed dimension, or a colored hatch.
- **Inferred:** likely intent such as load analysis, access study, or memory archive.
- **Reusable system:** relationships that can transfer without copying the sample.
- **Sample residue:** subject, wording, interface, color, exact fragment arrangement, brands, signatures, dates, locations, and accent shapes.

With one reference, describe it as a single observed example. Do not claim that every feature is a family-wide rule.

When generation follows analysis, deliberately choose a different fragment geometry and layout family while preserving the reusable system.
